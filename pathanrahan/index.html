Which course was he referring to?

The strongest match is Stanford CS343D: Domain-Specific Programming Models and Compilers. Its Fall 2021 schedule lists Hanrahan’s “Notation” lecture on November 11; later offerings include it too. Fred Kjolstad was the main instructor. The connection to the talk is an inference, since Hanrahan’s introduction doesn’t name the course.

Programming models for scientific computing, data science, and machine learning. Topics include dense and sparse computation, the separation of algorithms from schedules, and compiler construction.
